# VanEssen_2005

16 numbered figures assessed; 2 views and 67 provisional field/component measurements saved. Counts are observations, including overlapping domains and repeated drawings, not animals.

Figure 9A/B are right-hemisphere PALS-B12 atlas layouts, not identified individual animals. There is no local physical bar or valid areal-distortion correction, so results remain pixels only. External leaders and enlarged color boundaries were used for BA24, narrow cortical bands, V2d/V3/V3a/V7/LO and orbitofrontal labels. BA33 is not independently resolved. Literal s/l/r/m labels and an unidentified yellow cut component are not assigned invented area identities. Two one-pixel border slivers exceed the drafting reconciler’s fractional cutoff but have no overlap after the native two-pixel interior erosion audit.

[Source-toggle review](review/precision_review.html) · [All-figure assessment](review/gallery.html) · [Measurements](data/measurements.csv) · [Methods](documentation/methods.md) · [Field inventory](documentation/field_inventory.csv)

Rebuild from saved geometry with `python scripts/rebuild_all.py --java /path/to/java --ij-jar /path/to/ij.jar`. Python requires numpy, Pillow and pypdfium2; summaries require base R. `python scripts/measure_flatmaps.py --verify` checks saved outputs. Geometry is editable in each `figures/<map_id>/rois.json` or the corresponding native ImageJ ROI ZIP; coordinate changes must be rebuilt before use.
