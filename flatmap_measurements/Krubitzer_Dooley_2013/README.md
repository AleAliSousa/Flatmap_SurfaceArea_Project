# Krubitzer_Dooley_2013

9 numbered figures assessed; 14 views and 135 provisional field/component measurements saved. Counts are observations, including overlapping domains and repeated drawings, not animals.

Fourteen illustrative views cover figures 1, 2, 6C, 7 and 8A. Figure 7 somatotopic drawings are pixel-only. Other views use the applicable printed bars. The ghost bat is Macroderma gigas; developmental fruit-bat panels do not change that identification. FST subdivisions without separate closed borders remain NA. Enucleated-opossum domains explicitly include the named child fields; these are not additive observations or independent specimens.

[Source-toggle review](review/precision_review.html) · [All-figure assessment](review/gallery.html) · [Measurements](data/measurements.csv) · [Methods](documentation/methods.md) · [Field inventory](documentation/field_inventory.csv)

Rebuild from saved geometry with `python scripts/rebuild_all.py --java /path/to/java --ij-jar /path/to/ij.jar`. Python requires numpy, Pillow and pypdfium2; summaries require base R. `python scripts/measure_flatmaps.py --verify` checks saved outputs. Geometry is editable in each `figures/<map_id>/rois.json` or the corresponding native ImageJ ROI ZIP; coordinate changes must be rebuilt before use.
